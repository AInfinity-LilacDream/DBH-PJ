# Lab5 Monorepo Skeleton

This folder is reserved for the frontend and backend implementation of the campus Q&A system.

## Structure

```text
lab5/
  apps/
    server/      Express backend
    web/         React frontend
  packages/
    shared/      Shared constants, types, and validators
  docs/          API and implementation notes
  scripts/       Local helper scripts
```

The database schema and seed workflow are inherited from `lab4`.
